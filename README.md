# ODE-Numerical-Methods
A collection of numerical methods for solving ordinary differential equations (ODEs), including mathematical formulations, implementations, and simulations.

## Figure-Eight orbit
This is a periodic symmetric orbit where the particles follow a figure eight trajectory in the
plane. The orbit is such that the three masses chase one another around a single figure-eight shaped
curve.
